MS Phoenix - TradePulse

A personal research project on market data.

What it is

A software project, written in C# on .NET, that collects market candle data from exchanges and brokers and stores it in a database so that trading ideas can be analysed and tested on historical data. The source code of the collector is public.

Integrations

It talks to exchanges and brokers only through their official public APIs. The cTrader Open API application registered for this project reads data from the owner's own accounts and, for testing, places small orders on demo accounts. It is not offered to other people.

What it is not

It is not a trading service, a signal service or an investment product, and it does not manage anybody else's money.
